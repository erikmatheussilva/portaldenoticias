# Portal de Notícias

Portal de Notícias é um projeto de site estático que apresenta notícias em um layout responsivo e organizado. Ele foi desenvolvido com HTML, CSS e recursos estáticos que permitem a publicação e leitura de conteúdo editorial.

## Estrutura do Repositório

portaldenoticias/
├── assets/ # (imagens, ícones, etc.)
├── styles/ # Arquivos CSS e estilos
├── index.html # Página principal do portal
└── README.md # Documentação do projeto

## Funcionalidades
- Layout responsivo para desktop
- Estilização com CSS customizado  

## Tecnologias Utilizadas
| HTML       | Estrutura das páginas |
| CSS        | Estilização e layout |
