```markdown
# Portal de Notícias

Um site estático que apresenta notícias em um layout responsivo e organizado. Ele foi desenvolvido com HTML, CSS e recursos estáticos que permitem a publicação e leitura de conteúdo editorial.

## Estrutura do Repositório

```

````
portaldenoticias/
├── assets/                # Recursos estáticos (imagens, ícones, etc.)
├── styles/                # Arquivos CSS e estilos
├── index.html             # Página principal do portal
└── README.md              # Documentação do projeto

````

## Funcionalidades

- Layout responsivo para desktop  
- Estrutura organizada de seções de notícias  
- Estilização com CSS customizado  

## Tecnologias Utilizadas

| Tecnologia | Utilização |
|------------|------------|
| HTML       | Estrutura das páginas |
| CSS        | Estilização e layout |
